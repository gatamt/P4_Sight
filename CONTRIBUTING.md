# Contributing

Contributions to project-authored Apache-2.0 material are accepted under
Apache-2.0 unless the contributor explicitly states otherwise and the project
accepts those terms. Contributions to files marked GPL-2.0-only must be
submitted under GPL-2.0-only.

Do not copy register tables, drivers, tuning data or documentation from a source
that cannot legally be redistributed under the destination file's license.
Preserve all upstream copyright notices, SPDX identifiers and license files.
Document the source and license of newly introduced third-party material in
`docs/THIRD_PARTY.md`.

Keep changes focused. Camera or ISP changes should identify the tested hardware,
ESP-IDF version, sensor mode, MIPI lane count, link clock and observed frame
size.
