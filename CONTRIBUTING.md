# Contributing

Contributions to project-authored material are accepted under the Apache License
2.0, the same license used for that material in this repository. By submitting a
pull request, you confirm that you have the right to provide the contribution
under those terms.

Do not copy register tables, drivers, tuning data or documentation from sources
that cannot legally be redistributed. Changes to vendored or reference material
must preserve all upstream copyright notices, SPDX identifiers and license files.
Document the source and license of any newly introduced third-party material in
`docs/THIRD_PARTY.md`.

Keep changes focused and include the tested hardware, ESP-IDF version, sensor
mode, MIPI lane count, link clock and observed frame size when changing camera or
ISP behavior.
